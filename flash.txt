🗞️ 市場快訊｜11/12 區塊先生每日新聞快訊

美國10月通膨高於預期，市場預期聯準會12月升息，但AI概念股財報帶動美股與半導體族群反彈，比特幣則在7.3萬至7.5萬美元間震盪。
今日留意聯準會官員對升息幅度的表態、美元與日圓走勢，以及Anthropic IPO進度。

【幣圈】
<a href="https://www.kucoin.com/news/flash/bitcoin-price-rebounds-on-nov-11-2026-amid-etf-outflows-and-market-volatility">比特幣測試7.3萬美元支撐，現貨ETF近三週淨流出</a>
報導指比特幣一度升破7.5萬美元，24小時低點約7.37萬美元，連續五週收跌後再度測試7.3萬美元支撐。美國現貨比特幣ETF近三週淨流出約11.8億美元，總資產約959億美元。

<a href="https://crypto.news/goldman-citi-270m-dollar-stablecoin-venture">高盛、花旗等21家金融機構合資穩定幣公司獲約2.7億美元承諾</a>
彭博報導，參與機構承諾約2.7億美元，涵蓋新公司前五年營運成本。成員包括美國銀行、德意志銀行、瑞銀等，計畫先推出美元穩定幣，目標2027年上半年上線，尚未取得發行許可。

<a href="https://www.coindesk.com/tech/2026/11/11/live-news-coreweave-jumps-14-as-earnings-fuel-rebound-across-battered-ai-stocks">倫敦證交所放寬加密ETN規範，德意志銀行數位資產託管上線</a>
CoinDesk指出，倫敦證交所放寬專業投資人加密ETN的上市指引，為槓桿型比特幣與以太幣產品鋪路。德意志銀行也為歐洲機構客戶推出數位資產託管服務，涵蓋比特幣、以太幣與穩定幣。

【金融】
<a href="https://www.marketscreener.com/news/stocks-end-higher-as-coreweave-results-ease-ai-spending-worries-ce785edbd18cf726">美股收高，費城半導體指數大漲5.7%</a>
路透報導，標普500上漲1.31%至7,619.38點，那斯達克上漲1.60%，道瓊上漲0.49%。科技類股漲2.7%，為11大類股中最強，VIX連續第四個交易日下滑至17.49。

<a href="https://www.1049thewolf.com/2026/11/11/trading-day-ai-cheer-banishes-rate-hike-fear/">Waller：12月升息50個基點在考慮之列，美元指數創高</a>
路透報導，聯準會理事Waller表示12月升息2碼（50個基點）可列入考慮。聯準會9月已升息25個基點、10月暫停。美元指數升至去年4月以來高點，美元兌日圓逼近160。

<a href="https://www.manilatimes.net/2026/11/11/business/foreign-business/us-stocks-fall-on-hot-inflation-report-as-nvidia-tumbles-again/2467219">布蘭特原油一度跌破90美元，收在91.49美元</a>
法新社報導，布蘭特原油週二盤中一度跌破每桶90美元，為8月以來首次，終場收在91.49美元，下跌1.2%。同日美國10月通膨降溫幅度不如預期，美股三大指數收低。

【AI】
<a href="https://www.marketscreener.com/news/wall-street-set-for-higher-open-as-coreweave-results-temper-ai-spending-concerns-ce785edbdf88fe27">CoreWeave財報提振AI基建股，股價單日大漲逾兩成</a>
CoinDesk報導，CoreWeave第三季營收36.6億美元，年增168%，單季淨損7.09億美元，並上調全年營收預測至130億至133億美元。路透指其股價收漲24.7%，Nebius同步上漲15.4%。

<a href="https://www.manilatimes.net/2026/11/11/business/foreign-business/us-stocks-fall-on-hot-inflation-report-as-nvidia-tumbles-again/2467219">Anthropic擬於IPO募資最高640億美元</a>
法新社報導，Anthropic計畫於本月稍後的IPO募資最高640億美元，低於數週前市場傳出的約1,000億美元。該公司第三季營收升至170億美元，去年同期為14億美元。

<a href="https://www.foxnews.com/live-news/ai-news-china-super-intelligence-safety-11-11-26">美中擬在下週會面推進先進AI風險對話</a>
美國財政部長貝森特表示，川普與習近平預計在深圳APEC場邊會面時推進新的AI雙邊對話，並交流模型上線前的測試做法。雙方9月已同意設立AI重大事件的直接聯絡管道。
